# Book Tracker 📚

**Автор:** [Тамерлан]
**Язык:** Python 3.x

## Описание программы

Простое десктопное приложение для отслеживания прочитанных книг. Позволяет добавлять книги в список с указанием названия, автора, жанра и количества страниц.
Ключевые возможности:
*   **Добавление книг:** Ввод данных через удобную форму.
*   **Фильтрация:** Поиск книг по жанру или по количеству страниц (например, показать только книги объемом более 300 страниц).
*   **Сохранение данных:** Все добавленные книги сохраняются в файл `books.json`, поэтому они не пропадут после закрытия программы.
*   **Чтение данных:** При запуске программа автоматически загружает ранее сохраненный список.

## Инструкция по запуску

### Требования:
*   Установленный Python версии 3.6 или выше.
*   Библиотека `tkinter` (входит в стандартную библиотеку Python).

### Шаги:
1.  Установите Python с официального сайта (если еще не установлен).
2.  Скачайте или склонируйте этот репозиторий на свой компьютер.
3.  Откройте папку проекта в терминале/командной строке.
4.  Запустите приложение командой:
    ```bash
    python book_tracker.py
    ```
*(или `python3 book_tracker.py` на некоторых системах Linux/macOS)*

## Примеры использования

### Добавление книги:
1.  Перейдите на вкладку **"Добавить книгу"**.
2.  Заполните все поля: *Название*, *Автор*, *Жанр*, *Количество страниц*.
3.  Нажмите кнопку **"Добавить книгу"**. Книга появится в таблице ниже.
4.  Поля ввода очистятся автоматически.
> *Если вы забудете заполнить поле или введете буквы вместо числа страниц — программа покажет ошибку.*

### Фильтрация списка:
1.  Перейдите на вкладку **"Фильтр"**.
2.  Чтобы найти все книги определенного жанра (например, *Фантастика*), введите жанр и нажмите **"Применить фильтр"**.
3.  Чтобы найти объемные книги (например, более 400 страниц), введите число в поле *Страниц >* и нажмите кнопку.
4.  Чтобы показать весь список снова — просто оставьте поля фильтра пустыми и нажмите кнопку.
