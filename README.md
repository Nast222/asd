# Random Quote Generator 📜

**Автор:** [Тамерлан]
**Язык:** Python 3.x

## Описание программы

Графическое приложение для генерации случайных цитат. Программа содержит встроенную базу известных высказываний и позволяет пользователям добавлять собственные.
**Ключевые возможности:**
*   **Генерация:** Получение случайной цитаты из общего пула (встроенные + добавленные пользователем).
*   **История:** Все сгенерированные и добавленные вручную цитаты сохраняются в список истории.
*   **Фильтрация:** Поиск по истории по автору или теме.
*   **Сохранение:** История сохраняется в файл `quotes.json` и загружается при следующем запуске.
*   **Валидация:** Проверка на заполнение обязательных полей при добавлении новой цитаты.

## Инструкция по запуску

### Требования:
*   Установленный Python версии 3.6 или выше.
*   Библиотека `tkinter` (входит в стандартную библиотеку Python).

### Шаги:
1.  Установите Python с официального сайта (если еще не установлен).
2.  Скачайте или склонируйте этот репозиторий на свой компьютер.
3.  Откройте папку проекта в терминале/командной строке.
4.  Запустите приложение командой:
    ```bash
    python quote_generator.py
    ```
*(или `python3 quote_generator.py` на некоторых системах Linux/macOS)*

## Примеры использования

### Генерация цитаты:
1.  Нажмите кнопку **«Сгенерировать цитату»**.
2.  Цитата и её автор появятся в верхней части окна.
3.  Сгенерированная цитата автоматически добавится в историю справа.
4.  Повторное нажатие может выдать ту же самую цитату.

### Добавление своей цитаты:
1.  В разделе **«Добавить свою цитату»** введите текст в большое поле.
2.  Укажите автора в поле ниже.
3.  Нажмите кнопку **«➕ Добавить цитату»**.
4.  Цитата появится в истории. Поля ввода очистятся автоматически.
> *Если вы оставите поля пустыми — программа покажет ошибку.*
